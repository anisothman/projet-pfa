# Projet PFA

## Description

## Installation
1. Cloner le repo :
git clone https://github.com/anisothman/projet-pfa.git

2. Créer l'environnement virtuel :
python -m venv venv

3. Activer l'environnement :
venv\Scripts\activate

4. Installer les dépendances :
pip install -r requirements.txt

5. Copier le fichier .env :
cp .env.example .env

6. Remplir la clé SerpAPI dans .env
